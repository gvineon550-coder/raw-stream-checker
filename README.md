# 🎯 Raw Stream Checker

Автономный самообучающийся парсер и чекер IPTV. Парсит источники «как есть», проверяет каждый поток через `ffprobe`, собирает рабочий плейлист. Умный UA-подбор, кэш живых/мёртвых, адаптивные таймауты, единые категории и логотипы из iptv-org API.

## ⚙️ Как это работает

- **Источники:** из `sources.txt` (формат `имя|url|приоритет`)
- **Категории:** M3U → API iptv-org по `tvg-id` → API по имени → `📦 Разное`
- **Логотипы:** M3U (только HTTPS) → API iptv-org по `tvg-id`
- **Нормализация:** `Sports` и `Спорт` → `⚽ Спорт`, `Movies` и `Кино` → `🎬 Кино`
- **Фильтр мусора:** расширения, приватные IP, редиректы, битые протоколы
- **Проверка:** HTTP pre-check + `ffprobe` + умный перебор UA по хосту
- **Самообучение:** запоминает рабочий UA для каждого хоста
- **Кэш:** живые 6ч, мёртвые 30 дней, таймауты адаптивные
- **HLS:** master-плейлист → variant stream
- **Защита:** публикация отменяется если живых < 15%

## ⚖️ Дисклеймер

Этот проект **не хранит и не транслирует** видеоконтент. Все потоки берутся из открытых источников (в частности, репозитория [iptv-org](https://github.com/iptv-org/iptv)). Права на каналы и передачи принадлежат их правообладателям. Проект создан для личного использования и не преследует коммерческих целей.
